# surf-topo
An efficient computational framework for prediction of 3D surface topography of machined surfaces 

High-performance simulation for generating machined surface and tool trajectory data in milling processes.
The project is implemented in C++ with Python bindings via pybind11 for easy scripting and analysis.

---
## 1. Project Structure and Applications

The developments are implemented in the following components:

- **Simulation (`simulation` module)** — `simulation.cpp`  
  This module defines the cutting tool geometry, number of edges, angles, and kinematic parameters. It provides three main run functions:

  1. **`run`**  
     Performs the milling simulation, including surface and trajectory computation.

  2. **`compute_surface`**  
     Computes the machined surface as a point cloud based on tool geometry and motion.

  3. **`compute_trajectory`**  
     Computes the tool tip trajectory points over time.

- **Python Interface (`machtopo` module)** — `machtopo.cpp`  
  This module provides Python bindings to create tools, run simulations, and retrieve surface and trajectory data. It exposes the following functions:

  1. **`run`** → `run_simulation`
  2. **`compute_surface`** → `run_surface_simulation`
  3. **`compute_trajectory`** → `run_trajectory_simulation`

All components are free and licensed under **MIT**.  
External libraries (Eigen, pybind11) may have their own licenses.

Other applications or extensions are not included in this repository.

## 3. Compilation

Navigate to the CMake helper scripts directory:

```bash
cd machtopo/cmake/
```

Run the configuration script:

### Linux / macOS

```bash
./configure.sh
```

### Windows

```bat
configure.bat
```

This will configure and build the project using CMake, generating the `build/` and `bin/` directories.

---

## 4. Setting Up the Python Environment

Before running Python scripts that use the compiled module, add the `bin/` folder to your `PYTHONPATH`.

### Linux / macOS

```bash
export PYTHONPATH=/path/to/machtopo/bin:$PYTHONPATH
```

### Windows

```bat
set PYTHONPATH=C:\path\to\machtopo\bin;%PYTHONPATH%
```
or

```powershell
$env:PYTHONPATH = "C:\path\to\machtopo\bin"
```

and check if set properly

```powershell
python -c "import sys; print(sys.path)"
```

Replace `/path/to/machtopo` with the absolute path to your project folder.

## 5. Running Simulations

Simulations are run using the `data_set_builder.py` script and a JSON case file.

### Example

```bash
python3 data_set_builder.py test_case_A1.json
```

The case file defines:

- Tool parameters  
- Workpiece size  
- Grid resolution  
- Simulation settings  

The script generates:

- **Surface points**  
  A point cloud representing the machined workpiece.

- **Trajectory points**  
  Positions of the tool tip for each time step and cutting edge.

During execution, a **folder containing plots** is automatically created in the **current execution directory**.  
This folder stores visualization outputs generated using `plot_utils.py`.

---

## 6. Configuration File Modes

The simulation behavior is controlled via the `"mode"` field in the case file.

Two modes are supported:

- `"single"` — runs one simulation with fixed parameters  
- `"dataset"` — generates a dataset by sampling a parameter space and stores the results in an HDF5 file

---

## 7. Single Simulation Mode

In **single mode**, one milling simulation is executed using fixed input parameters.

### Example Single Mode Case

```json
{
  "mode": "single",
  "case_name": "test_case_A1",

  "input": {
    "vc": 170.0,
    "fz": 0.6,
    "ap": 0.5,
    "Td": 10.0,
    "z": 2,
    "gama_f": 0.6,
    "gama_p": 0.0,
    "ri": 5
  },

  "fixed": {
    "phi": 90,
    "eps_a": 0.003,
    "eps_r": 0.011,
    "x_0": 5.0,
    "y_0": -5.0,
    "z_0": 0.0
  },

  "grid": {
    "grid_base": 500,
    "length": 5.0
  },

  "integration": {
    "delta_t": 0.8e-6
  }
}
```

Run using:

```bash
python3 scripts/data_set_builder.py cases/single/test_case_A1.json
```

## 8. Dataset Generation Mode

In **dataset mode**, multiple simulations are generated by sampling a parameter space.  
The results are stored in a single **HDF5 (`.h5`) file**.

### Example Dataset Case

```json
{
  "mode": "dataset",
  "case_name": "dataset_simulation",

  "input": {
    "vc": [40.0, 120.0],
    "fz": [0.05, 0.40],
    "ap": [0.1, 0.5],
    "gama_f": [0.0, 1.0],
    "gama_p": [0.0, 0.2],
    "Td": [6.0, 8.0, 10.0],
    "z": [2, 3, 4],
    "ri": [1, 2]
  },

  "fixed": {
    "phi": 0.0,
    "eps_r": 0.01,
    "eps_a": 0.02,
    "x_0": 0.0,
    "y_0": 0.0,
    "z_0": 0.0
  },

  "grid": {
    "grid_base": 200,
    "length": 5.0
  },

  "integration": {
    "delta_t": 8e-7
  },

  "sampling": {
    "method": "lhs",
    "n_samples": 100,
    "seed": 42
  }
}
```

Run using:

```bash
python3 scripts/data_set_builder.py cases/dataset/config_dataset.json
```

## 9. Using the Python Interface

Once the `machtopo` module is compiled and `PYTHONPATH` is set, it can be used directly:

```python
import machtopo

tool = machtopo.Tool(
    gama_f=30.0,
    gama_p=10.0,
    D=10.0,
    eps_r=0.2,
    eps_a=0.1,
    phi=0.0,
    omega=1000.0,
    v_f=50.0,
    x_0=0.0, y_0=0.0, z_0=0.0,
    fz=0.05,
    ri=5.0,
    z_n=4
)
```

```python
sim = machtopo.Simulation(
    tool,
    d_x=50, m=100,
    d_y=50, n=100,
    z_level=2.0,
    edge_points=50,
    t_total=1.0,
    delta_t=0.01
)
```

```python
surface_points = []
sim.run_surface_simulation(surface_points)

trajectory_points = []
sim.run_trajectory_simulation(
    trajectory_points,
    trajectory_downsample=1
)
```

## 10. Python Convenience Function

```python
surface, trajectory = machtopo.run_simulation(
    tool,
    d_x=50, m=100,
    d_y=50, n=100,
    z_level=2.0,
    edge_points=50,
    t_total=1.0,
    delta_t=0.01,
    trajectory_down_sample=1
)
```

This returns **NumPy arrays** for surface and trajectory points.

---

## 11. Notes

- The simulation assumes rigid tool geometry and does not model material deformation.
- Surface resolution depends on grid resolution and tool discretization.
- Trajectory points are computed per cutting edge.
- The `build/` and `bin/` directories are generated automatically by CMake.
